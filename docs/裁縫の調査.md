## 1. 盤面(確定)

| 部位 | マス数 | 並び |
|---|---|---|
| からだ上 | 9 | 3行×3列 |
| ぬいぐるみ | 7 | 3行×3列から、左上と右上が欠けた形 |
| からだ下 | 6 | 3行×2列 |
| ウデ・ラグ | 6 | 2行×3列 |
| アタマ | 4 | 2行×3列のうち、上の段は中央だけ(凸の形) |
| 足 | 4 | 2行×2列 |

- **特技の当たる形**:
  - ヨコぬい: 選んだマスと右
  - 滝のぼり: 選んだマスと上
  - たすき: 選んだマスと右上
  - 逆たすき: 選んだマスと左上
  - 水平: ヨコ3
  - 大滝: タテ3
  - 巻きこみ: 中心と上下左右
- **布からはみ出す時**: 収まる位置へずれる(例: 水平ぬいは、1列目・3列目を選んでも2列目になる)。
  - 巻きこみぬいは、選んだマスが中心のまま。はみ出した分は無視される。
- **欠けた位置を選んだ時**: 範囲内にある実在のマスだけを縫う。1つもなければ、手は実行されない。
- **複数マスの特技は、マスごとに別々に値と会心を決める。** 黄色・赤のマスにも当たる。

## 2. ターンの進み方(確定。処理の順)

1. **ターンの始め**:
   1. **ぬいパワーを決める**。優先順:
      1. 精神統一で固定中なら、その強さ。
      2. 直前のシフトで決まった強さがあれば、その強さ。
      3. それ以外は、順番(ぬいパワーサイクル)の今の位置の強さ。
      - 「？」は、ここで弱い・普通・強い・最強・会心×２ のどれかになる。**5種類の確率は仮定(等確率)**。
   2. **布の特性**: 5・9・13…ターン目の始めに起きる(1章の5)。
   3. **まれに集中力回復**(Lv70〜): 残り集中力10以下なら、10%(推定)で +30。1ゲームに1回だけ。
2. **行動**: 集中力が足りない特技は使えない(ターンは進まない)。「しあげる」はいつでもできる。
3. **ターンの終わり**:
   1. 必殺チャージの抽選。
   2. 精神統一の残りを1減らす。
   3. **固定が終わっている時だけ、順番の位置を1つ進める**。

### 2-1. ぬいパワー(確定)

| 強さ | 係数 |
|---|---|
| 弱い | 0.5 |
| 普通 | 1 |
| 強い | 1.5 |
| 最強 | 2 |
| 会心×２ | 1 |

- 順番は商材ごとに決まった繰り返し。会心×２は、順番には入っていない。
- 会心×２は2種類ある。表示は同じ:
  - **シフト会心**(シフトで出たもの): 会心率2倍。
  - **ランダム会心**(「？」から出たもの): 会心率は**仮定で補正なし**。
- **精神統一**(消費7):
  - 使ったターンの強さを、次のターンから3ターン固定する。
  - **固定の間、順番は止まる**。固定が終わると、使ったターンの次の位置から続く。
  - 固定中にもう一度使うと、そこから3ターンに延びる。
  - シフト会心を固定すると、会心率2倍も持ち越す。
- **ぬいパワーシフト**(消費7):
  - 次のターンの強さを、今の強さ以外の4種類(弱い・普通・強い・最強・会心×２ のうち)から等確率で決める。
  - **順番の位置は、ふだん通り進む**。差し替わった位置は、飛ばされる。
  - 精神統一の固定中に使った場合: 処理では、決まった強さは固定が終わるまで待ち、固定の次のターンに使われる。
    ページには書かれていない、処理だけで分かる扱い。
- **必殺「無我の境地」**:
  - 消費0。1ターン使う(順番も進む)。
  - 使ったあとは、そのゲームの終わりまで会心率2倍。1ゲームに1回。

## 3. 1回に縫える値(確定)

- **値** = 切り上げ( 切り上げ( 切り上げ( 基礎値 × 特技倍率 ) × ぬいパワー係数 ) × マス補正 )
  - 基礎値: 12〜18 の7通り、等確率。
  - 特技倍率:
    - ぬう・ねらい・2〜3マスの特技: 1
    - かげん: 0.5
    - 半かげん: 0.75
    - 2倍: 2
    - 3倍: 3
    - 巻きこみ: 中心 1.5・周り 0.75
  - **マス補正**:
    - ふだん: 1
    - しつけがけ: 2
    - 光布の光ったマス: 2
    - 両方: 4
- **会心**: 値が2倍。基準値を越える分は切り捨て(基準値でぴったり止まる)。
  - **すでに基準値に達しているマスでは、会心の抽選をしない。**
- **しつけがけ**(消費13):
  - そのマスのマス補正を2倍にする。重ね掛けはできない。
  - **そのマスを一度縫うと消える**。複数マスの特技・みだれぬい・糸ほぐしでも消える。
- **糸ほぐし**(消費16):
  - 戻す量 = 切り捨て( 基礎値 × ぬいパワー係数 × マス補正 )。会心なし。0より下には戻らない。
  - **基礎値は 6〜9 の4通り、等確率**。
  - 例:
    - 弱い: 3・3・4・4
    - 普通: 6・7・8・9
    - 強い: 9・10・12・13
    - 最強: 12・14・16・18
- **みだれぬい**(Lv80・消費7):
  - 4つの違うマスを、選んだ順に 2倍・1倍・1倍・0.5倍で縫う。
  - **選ぶマスは、全マスから等確率(仮定)**。黄色・赤のマスも候補に入る。
  - 会心は、4マスそれぞれで別に抽選する。
- **半かげんぬい**(Lv75・消費12): 1マス・0.75倍。
- 1マスの縫った量の上限は999。

## 4. 会心率(式は確定、一部の値は推定)

**会心率 = ( (針の会心率 + コツ + 会心率アップ) × ねらい倍率 + 固定値上昇 ) × 必殺補正 × シフト会心補正**

| 項目 | 値 | 区分 |
|---|---|---|
| 針の会心率 | 下の表(★ごと) | 確定 |
| コツ(そのレシピで★3を作ると必ず、★2だと一定の確率で取得) | +1.0% | 推定 |
| 会心率アップ(Lv10以上) | 合計 +0.1%(Lv10・20・30 の3つ合わせて) | 推定 |
| ねらい倍率(ねらいぬいのターン) | 7倍 | 確定 |
| 固定値上昇: 虹布の消費1.5倍のターン | +24%(足し算) | 推定 |
| 固定値上昇: 光布の光ったマス | +24%(足し算) | 推定 |
| 必殺補正 | 2倍 | 確定 |
| シフト会心補正 | 2倍 | 確定 |
| ランダム会心の補正 | なし | 仮定 |

例(光の針★3・Lv80・コツあり):

| 場面 | 会心率 |
|---|---|
| 基本 | 5.7% |
| ねらいぬい | 39.9% |
| 虹布の会心ターン・光ったマス | 29.7% |
| その両方にねらいぬい | 63.9% |
| 必殺のあとのねらいぬい | 79.8% |

- 実測とのつき合わせ:
  - 期待値はプラス!の実測(ねらいぬい 5,200回、シフト会心 3,100回)は、この式(コツあり)と、ほぼ合う。z は −2.4〜+2.2。
  - メガしまね(2017)の光ったマスの実測は 25.3%(1000回)で、式の 29.7% より低い(z = −3.0)。
    古い実測なので、参考までに書いておく。

| 針 | 集中力 | 会心率 ★0/★1/★2/★3 | 生産開始時の効果 |
|---|---|---|---|
| 銅 | +0 | 1.0/1.1/1.2/2.0% | |
| 鉄 | +10 | 1.5/1.6/1.7/2.5% | |
| 銀 | +15 | 2.0/2.1/2.2/3.0% | |
| プラチナ | +25 | 2.5/2.6/2.7/3.5% | |
| 超 | +35 | 3.0/3.1/3.2/4.0% | |
| 奇跡 | +50 | 3.3/3.4/3.5/4.3% | **30%** で集中力 +30 |
| 光 | +45 | 3.6/3.7/3.8/4.6% | **10%** で必殺チャージ済み(Lv40以上) |

- **必殺チャージ**(仮定): ダメージを与えたターンの終わりに抽選する。
  - 確率 = 0.00233 × そのターンに与えたダメージ × 針の会心率(小数。光★3 なら 0.046)。
  - 1ゲームで1回まで。Lv40以上。
  - 「必殺率小アップ」(Lv45・57・62)の効果は不明で、入っていない。

## 5. 布の特性(確定)

- **5・9・13・17…ターン目の始め**に起きる。その後で、そのターンの手を打つ。
  - 4・8・12…ターン目の後、と言っても同じ。
  - どの特技も1ターンと数える(精神統一・シフト・必殺も)。
- **再生布(回復の布)**:
  - 黄色(差4以内)でないマスのうち、「縫った量 ÷ 基準値」が一番大きいマスが 12〜16(等確率)戻る。
  - 同じ割合が複数あれば、等確率で1つ(仮定)。
  - 縫った量より多くは戻らない。
- **虹布(虹の布)**:
  - 5・13・21…ターン目: 消費集中力が半分(切り上げ)。
  - 9・17・25…ターン目: 消費1.5倍(切り上げ)で、会心率 +24%。このターンに縫う全マスに乗る。
- **光布(魔法の布・ピンク布)**:
  - **白のマス(残りが5以上)** から等確率(仮定)で1つ光る。黄色と赤は光らない。
  - そのターンだけ、光ったマスはマス補正2倍・会心率 +24%。
- **通常布**: なし。

## 7. できのよさ(確定)

- **各マスの誤差**:
  - 4以下: そのまま数える。
  - **5〜8: 9として数える**。
  - 9以上: そのまま数える。
- 全マスの合計で決まる。

| マス数 | ★3 | ★2 | ★1 | ★0 | 失敗 |
|---|---|---|---|---|---|
| 9(からだ上) | 8以下 | 17以下 | 36以下 | 49以下 | 50以上 |
| 7(ぬいぐるみ) | 5以下 | 17以下 | 27以下 | 30以下 | 31以上 |
| 6(からだ下・ウデ・ラグ) | 4以下 | 11以下 | 24以下 | 39以下 | 40以上 |
| 4(アタマ・足) | 2以下 | 7以下 | 16以下 | 29以下 | 30以上 |

- **実装時期の古い一部のレシピ**(データで印のある31レシピ)は、★3・★2 だけ厳しい。
  - 9マス: ★3 6以下・★2 13以下
  - 6マス: ★3 3以下・★2 8以下
  - 4マス: ★3 1以下・★2 5以下
- 黄色に入っていないマスが1つでもあると、そのマスだけで9以上になり、どの部位でも★3の上限(最大8)を越える。
  つまり、**★3 は全マスが黄色の時だけ**。

## 9. それでも残る不明点

資料で「仮定」「推定」とされている所と、処理だけで分かる扱いです。エンジンへの効き目が大きい順に並べました。

| # | 不明点 | 資料の扱い | エンジンへの効き目 |
|---|---|---|---|
| 1 | **「？」が5種類それぞれ何%か** | 仮定: 等確率(各20%) | **大**。「？」は362レシピにあり、最新装備の順番の半分近くが「？」。<br>弱いが来る確率は、仕上げの計画を直接左右する。 |
| 2 | **ランダム会心(「？」から出た会心×２)の会心率** | 仮定: 補正なし | 中。「？」の 1/5 で来る。シフト会心と同じ2倍なら、ねらいぬいの価値が変わる。 |
| 3 | **虹布の会心ターン・光ったマスの +24%** | 推定 | 中。虹布・光布の作戦の中心。<br>古い実測(メガしまね 1000回)は、これより低めだった。 |
| 4 | **コツ +1.0%・会心率アップ合計 +0.1%** | 推定 | 小。ねらいぬいで ±1%ほど。実測(期待値はプラス!)とは合う。 |
| 5 | **みだれぬいが選ぶマス** | 仮定: 全マスから等確率(黄色も含む) | 中(Lv80 だけ)。<br>黄色のマスを避けるかどうかで、終盤に使えるかが変わる。 |
| 6 | **必殺チャージの確率** | 仮定(作った値)。必殺率アップの効果も不明 | 小〜中。エンジンでは「来たら使い方を考える」形にすれば、確率は要らない。 |
| 7 | **まれに集中力回復の確率 10%** | 推定 | 小(残り10以下の時だけ)。 |
| 8 | 再生布で割合が同じマスが複数ある時 | 仮定: 等確率 | 小。 |
| 9 | 光布でどのマスが光るか | 仮定: 白のマスから等確率 | 小〜中。光布の作戦では、全部のマスを会心の範囲にそろえるので、等確率でよい見込み。 |

| 11 | ラグ・ぬいぐるみのレシピ | データなし | 対象にしなければ不要。 |

鍛冶と同じく、実際の記録(「？」で何が来たか、ねらいぬいの会心)を集めれば、後から直せます。
1 は1種類あたり100回で ±8% ほどの幅で分かります。
